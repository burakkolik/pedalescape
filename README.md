# Pedal Escape: Bike Run

Bisikletinle arkandan gelen fırtınadan kaç! Flutter ile yazılmış, harici oyun
motoru kullanmayan, eski telefonlarda da akıcı çalışacak şekilde optimize
edilmiş sözde-3D sonsuz koşu oyunu.

- Kontroller: sağa/sola kaydır (şerit), yukarı (zıpla), aşağı (eğil).
- Güçlendiriciler: Kalkan, Mıknatıs, Turbo, x2 Puan.
- Mağaza (bisiklet/forma renkleri), görevler, grafik kalite ayarı.

Geliştirme durumu için `ilerleme.txt` dosyasına bakın.

```
flutter test
flutter build apk --release --split-per-abi
```
